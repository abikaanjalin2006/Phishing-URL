# Phishing URL Detection Project

## 📌 Overview
This project is a **Phishing URL Detection web application** developed as a cyber security–focused mini project.  
It helps identify whether a given URL is **phishing (malicious)** or **legitimate**, using rule-based URL analysis.

The project is built using **Python and Flask**, with a simple web interface for user interaction.

---

## 🎯 Objectives
- To understand phishing attacks and malicious URLs
- To analyze URLs based on security-related features
- To build a simple and effective phishing detection system
- To gain hands-on experience in Python, Flask, and Cyber Security concepts

---

## 🚀 Features
- User-friendly web interface
- URL validation and analysis
- Detects suspicious/phishing URLs
- Login and signup system (if implemented)
- Cyber security–oriented project structure
